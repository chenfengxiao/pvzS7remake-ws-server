# S丐 1.8.0 · 双人 Versus 完整可玩版

本包基于 S丐 1.7.8 最新联机主线新增 **真人双人 Versus（植物玩家 VS 僵尸玩家）** 与 **本地人机对练**。旧联机斗蛐蛐模式保留并与 Versus 房间隔离。

> **1.7.8 主线同步**：保留 1.7.6 保护伞立即弹飞/攻击 CD 锁定；加入 1.7.7 雪橇车地刺穿刺；加入 1.7.8 B 键文字开关对僵尸元素层数文字的统一控制。
> 双人 Versus 入口已改为静态 DOM + 安全事件绑定；2服只在创建/加入房间时建立 MQTT 反向隧道，入口导航与网络握手解耦。

## 入口

打开原工程推荐启动入口后，在首页选择：

- **双人对战｜植物 VS 僵尸｜真人联机**：两名真人玩家；仅 1服 / 2服支持实时画面流。
- **人机对练**：本地单机；先选植物或僵尸，AI 自动接管另一方。

## 真人 Versus 的同步原则

- **房主是唯一战斗权威**：植物、僵尸、弹道、资源、CD、Variant Meter、胜负全部只在房主战斗实例计算。
- **房客不运行本地战斗模拟**：只接收房主 Canvas 的压缩图像画面。
- 房客输入以结构化动作发送到房主，由房主调用与人机模式相同的 `S7VersusBattle.performAction()`。
- 房客界面显示真实往返延迟，单位 **cs（1 cs = 10 ms）**。
- 战斗中不迁移房主权威。房主权威丢失则终止本局，防止形成两个不同真相状态。

## 房间 / Draft

- 两名玩家先 **抢僵尸 / 抢植物**，服务器按先到先得判定。
- 房主可选 **6槽 / 7槽**。
  - 6槽 = 固定经济核心 + 5 张战斗卡。
  - 7槽 = 固定经济核心 + 6 张战斗卡。
- 可选 **No-BP / 有BP**。
- 僵尸 Draft 先手。
- 植物固定经济核心：双子向日葵；僵尸固定经济核心：墓碑。

## 真人与人机操作对等

植物玩家：
- 1～7 选卡；点击战场种植。
- `Q` 铲除。
- 可使用灰烬、经济核心和全部 Draft 入选植物。

僵尸玩家：
- 1～7 选卡；点击战场合法部署区放僵尸。
- `V` 切换普通部署 / 100% 保证变种。
- 可使用墓碑、普通/保证变种、指令僵尸及全部 Draft 入选僵尸。

以上动作在人机与真人模式走同一个执行入口；真人房客只上传输入，绝不本地结算。

## 主要 Versus 规则

- 开局：75 阳光 / 75 脑光。
- 免费双子：2-1、4-1；免费墓碑：2-9、4-9。
- 5:00 后禁止再部署新的产光单位，已有经济单位继续产出。
- 5:00 后每 20 秒双方各获得 +50 天空资源（2×25）。
- 40:00 未决：平局。
- 僵尸保留确定性时间 HP 成长。
- Variant Meter 为确定性累计机制；失败购买不推进。
- 付费 100% 变种不会推进、消耗或重置免费 Variant Meter。
- 白眼巨人：300 脑光，CD 50 秒；100% 变种总价 500。
- 红眼巨人：550 脑光，CD 50 秒；100% 变种总价 850。

## 网络限制

实时 Versus 图像流只允许走 **1服 / 2服**。3服公共 MQTT 灾备线路继续用于原有灾备联机，不承载连续战斗图像流。

当前自动化环境已完成规则、语法、双端协议、Canvas/HUD 与视觉回归；但该环境没有安装 `server/node_modules/ws`，因此**本次封包前没有完成真实公网两台物理电脑的 WebSocket 实连 smoke test**。首次实际两机测试建议优先使用 1服或2服。

详见 `docs/VERSUS_验收报告_20260826.md`。
