# 1.2.4 僵尸临界值重划分与盲盒路障血量修订

## 一、统一规则

所有**原本具有临界值**的僵尸，保持本体总血量不变，重新划分为：

```text
新临界值 = floor(本体总血量 / 3)
新非临界段 = 本体总血量 - 新临界值
```

冰车与投篮车改为固定199点临界值，本体总血量保持不变：冰车为1151非临界+199临界=1350，投篮车为451非临界+199临界=650。蹦极、巨人、红眼巨人、黑橄榄等其余无临界类型仍保持无临界值。

该规则同时覆盖：

- 基础僵尸注册表；
- 变种对本体总血量的改写；
- 1/5～5/5随机血量档；
- 突袭气球的固定本体增血；
- 巨大白眼与超大红眼投出的强化小鬼；
- 旧存档或复制实体在后续动态改血时的临界值刷新。

### 极低血量档边界

冰车的最低随机血量档仍高于199，不受影响。投篮车在1/5血量档时本体总血量为130；为防止临界结算把当前血量反向抬高，该极端实例采用129点安全临界值。正常投篮车以及总血量不低于200的实例始终固定199点临界值。

## 三、盲盒路障

常规盲盒路障调整为：

- 防具最大生命值：370；
- 本体总血量：270；
- 临界值：90；
- 非临界段：180。

指令僵尸召唤的特殊指令盲盒仍保留独立的1点开盒防具规则，不与常规盲盒路障混用。
