# 发布检查清单

## 静态验证

- [ ] 所有 JS 通过 `node --check`。
- [ ] `tools/verify_project.py` 返回 `ok: true`。
- [ ] 资源哈希和图片解码正常。

## 功能回归

- [ ] 普通模式和 V 时间轴模式均能开始、暂停和清场。

- [ ] 投手从左侧投掷篮生成子弹。
- [ ] 子弹按轨迹方向显示且不自转。

- [ ] 多宫格 2×2、5×5 和 10×10 可启动。
