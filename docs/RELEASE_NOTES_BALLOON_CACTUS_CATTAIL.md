# 变种气球、仙人掌、向日葵与猫尾草修复

## 规则口径

- “空中气球”只由 `isBalloonAir(z)` 判定，即 `z.type === "balloon" && z.air === true`。
- 气球被扎破或自然落地后立刻按普通地面僵尸处理，不再参与空中模式和空中优先级。

## 修复内容

1. 变种气球落地后清除空中移动锁，恢复普通速度档，敌方单位固定向左行走；遇植物才啃食。
2. 时间轴向日葵不再进入视频技能特效，固定使用旧版 JSPVZ 向日葵动画；产阳光和照耀规则不变。
3. 仙人掌本行存在空中气球时，只向空中气球发射并使用抬高身体动画；否则只攻击地面目标，并使用从用户视频 `7月25日(1).mov` 提取的正常发射动画。
4. 猫尾草本体和同行浮游炮优先选择仍在空中的气球；目标落地后不再保留空中优先身份。
5. 浮游炮小刺速度集中为 `3 格/秒`，在 25Hz 固定时钟下等于 `0.12 格/帧`。

## 验收

- 变种气球落地行走及遇植物啃食：PASS
- 仙人掌空中/地面双模式、动画和命中限制：PASS
- 向日葵旧版动画解析：PASS
- 猫尾草空中气球优先和动态重锁：PASS
- 浮游炮实际逐帧位移 0.12 格：PASS
