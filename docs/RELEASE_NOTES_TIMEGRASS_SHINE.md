# 逆时草接受向日葵照耀加速修复

日期：2026-08-01

## 规则

- 3阶及以上向日葵产生的左右侧向小阳光，可以把相邻格的逆时草识别为合法照耀目标。
- 小阳光抵达并消失后，逆时草获得4秒照耀。
- 照耀期间逆时草技能间隔沿用全局统一规则：基础间隔除以1.3。

## 实现

- 新增唯一目标注册表 `S7_SUNFLOWER_SHINE_TARGETS`。
- 新增统一判定函数 `s7SunflowerCanShinePlant()`。
- 侧向小阳光结算只调用统一判定函数，不为逆时草增加独立分支。

## 验收

- 逆时草基础技能间隔：15秒。
- 获得照耀后的间隔：11.538461538秒。
- 实测倍率：1.3。
- 浏览器真实卡牌点击种植与绘制同时通过。
