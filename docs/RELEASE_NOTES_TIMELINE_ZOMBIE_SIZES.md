# 时间轴巨人与冰车尺寸调整

## 变更范围

本次只调整 `V` 时间轴动画模式下的僵尸贴图显示尺寸，不修改实体坐标、碰撞框、攻击距离、碾压范围、冰道范围、速度、生命值或伤害。

- 突进巨人：保持改动前的巨人显示尺寸（1 倍基准）。
- 普通巨人：改为该基准的 2 倍。
- 巨大化巨人：改为该基准的 3 倍。
- 冰车僵尸：改为改动前冰车显示尺寸的 2 倍。

白眼巨人和红眼巨人分别保留原有的基础体型差异；武装状态不额外改变尺寸。巨大化状态优先于突进状态。

## 架构处理

尺寸层级集中在 `S7_TIMELINE_ZOMBIE_SIZE_TIERS` 与 `s7TimelineZombieSizeTier()`，由时间轴分层精灵和 Emoji 备用绘制共同读取。没有把视觉倍率写入实体工厂、碰撞或战斗模块。

## 回归门禁

- 静态验证锁定 1/2/3/2 四档倍率。
- 运行时烟测校验普通/突进/巨大化巨人的比例，以及冰车相对旧尺寸的 2 倍关系。
- 验证脚本检查视觉倍率未泄漏到几何、伤害和僵尸运行模块。
