# S丐 1.7.6 Versus 入口流程根因修复（2026-08-27）

## 本次修复

1. **双人对战 / 人机对练按钮“只闪虚影”根因修复**
   - 根因：新增模块错误地尝试隐藏不存在的 `#setup`，而真实首页容器是 `#startScreen`；新界面虽已显示，但被固定高层首页盖住。
   - 修复：新增统一 `S7ScreenNav` 与 `data-s7-entry` 首页入口路由；新模式按钮不再各自绑定首页跳转，也不再硬编码首页 DOM id。
   - 新增 `.versusEntryScreen` 固定顶层屏幕样式，防止入口界面再次落到首页下面。
   - 新增 `tools/test_versus_entry_flow.cjs` 回归测试，禁止重新引入 `hide('setup')` 与主界面 Versus 房间规则按钮。

2. **双人对战入口改为标准服务器选择流程**
   - 首页“双人对战” -> 与“联机对战”共用服务器选择界面 -> 选择 1服 / 2服 -> 创建或加入 Versus 房间。
   - 3服因当前不支持 Versus 实时画面同步，在双人模式下明确置灰并在占锁前拒绝进入。
   - 返回服务器选择时会断开本次 Versus 入口连接并释放当前服务器浏览器独占锁，避免幽灵占锁。

3. **首页按钮尺寸统一**
   - “进入斗蛐蛐 / 随机布阵开赛 / 联机对战 / 双人对战 / 人机对练”统一使用 `homeMainAction` 几何规格。
   - 双人 / 人机入口取消原先的大号双行卡片按钮。

4. **BP / 额外卡槽归位到房间内**
   - 首页移除“开启BP / 开启额外卡槽 / BP流程预览”。
   - 真人双人房间：房主在房间内设置 6/7 槽与 No-BP / 有BP。
   - 人机对练：改为“进入人机对练 -> 创建本地人机房间 -> 房间内选择阵营、6/7槽、No-BP/有BP -> 选卡 -> 战斗”。
