# S丐 1.7.6 双人 Versus 验收报告（2026-08-26）

## 1. 功能范围

已接入正式主线：真人双人 Versus、本地人机对练、6/7槽、BP/No-BP、抢阵营、服务器权威 Draft、房主唯一战斗权威、房客图像流、房客输入回传、cs 延迟、100%保证变种、重连/掉线、胜负/40分钟平局。

## 2. 权威同步架构

- Host：唯一运行 S丐战斗实体与规则。
- Server：只维护房间/Draft/身份和中继帧、输入、探针、结算；不运行战斗模拟。
- Guest：不创建权威战斗；只显示 Host Canvas 帧并上传输入。
- Guest 输入由服务器附加权威阵营信息，Host 再调用统一 `performAction()`。
- 图像采用压缩 WebP/JPEG 帧，旧帧可丢弃，避免弱网形成不断增长的排队延迟。

## 3. 人机 / 真人动作对等

统一执行入口覆盖：

- 植物：选卡、种植、经济核心、灰烬、铲除。
- 僵尸：选卡、普通部署、墓碑、100%保证变种、指令卡。
- 失败购买：不扣资源、不消耗 CD、不推进 Variant Meter。
- 付费保证变种：不推进/重置免费 Variant Meter。

## 4. 断线与权威安全

- 断线席位保留 120 秒。
- Guest 重连后输入序号安全重置，避免新输入被当旧包丢弃。
- Host 重连后画面序号从服务端记录继续，避免新帧被 Guest 当旧帧丢弃。
- Guest 超时/主动退出战斗：服务器按掉线弃权结算。
- Host 权威彻底丢失：整局终止，不迁移权威。
